# approachstrength.com

The Approach Strength website (GitHub Pages, custom domain `approachstrength.com`).

Generated by `scripts/build-site.py` in `rparker-sudo/approach`. Words come only from that repo's `docs/copy/website-copy.md`; legal pages only from its `docs/legal/`; prices only from `pricing.json` here; the administrator-preview sample data from `admin-preview.json` here (design doc §5.2). Screenshots in `assets/screens/` are demo-mode captures with sample data. Don't edit the HTML by hand.

Plain HTML and CSS: no scripts, analytics, cookies, forms, or third-party requests. Fonts are self-hosted (Inter and Inter Tight, SIL Open Font License, see `fonts/`).
